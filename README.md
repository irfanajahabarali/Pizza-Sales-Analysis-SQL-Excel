# 🍕 Pizza Sales Analysis — SQL & Excel

## 📊 Project Overview

This project is a **SQL and Excel Data Analysis learning project** focused on analyzing pizza sales data and creating an interactive Excel dashboard.
data
The project uses **MySQL** for  analysis and **Microsoft Excel** for KPI analysis, trend analysis and dashboard visualization.

The analysis provides insights into overall sales performance, order trends, pizza categories, pizza sizes and individual pizza performance.

---

## 🎯 Project Objectives

- Analyze pizza sales data using SQL
- Calculate important business KPIs
- Analyze daily and hourly order trends
- Compare sales across pizza categories
- Analyze sales by pizza size
- Identify top-performing pizzas
- Transform analytical results into Excel visualizations
- Create an interactive pizza sales dashboard

---

## 🛠️ Tools & Technologies

- **MySQL** – SQL querying and data analysis
- **Microsoft Excel** – Data analysis, Pivot Tables, Pivot Charts, and dashboard creation
- **GitHub** – Project documentation and version control

## 🔍 SQL Analysis

The pizza sales dataset was analyzed using SQL to answer different business-related questions.

The analysis includes:

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas per Order
- Daily Order Trends
- Hourly Order Trends
- Monthly Sales Trends
- Sales by Pizza Category
- Sales by Pizza Size
- Top-Selling Pizzas
- Pizza Quantity Analysis

The SQL queries and analysis screenshots are included in the project documentation file.
